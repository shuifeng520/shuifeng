# 审计智能体问答式对话窗口设计稿

本方案将系统从“菜单/步骤驱动”调整为类似 GPT、DeepSeek 的问答式工作台。用户不再先选择模块，而是在统一输入框中直接描述审计目标、上传资料、连接数据或要求生成 SQL；系统在对话中识别意图、沉淀上下文，并把资料、数据、方法和结果实时展示在右侧面板。

## 设计目标

- 主界面改为对话窗口：中间是用户与审计智能体的消息流，底部是统一输入框。
- 去掉左侧功能菜单，仅保留“历史会话/当前会话”列表，符合大模型产品使用习惯。
- 右侧固定上下文面板，持续展示资料状态、数据状态、方法执行、命中结果和可执行动作。
- 用户可以用自然语言完成“资料识别、数据接入、方法执行、结果导出”。
- 保留审计业务所需的可追溯性：对话、资料、SQL、执行结果和报告归档保持关联。

## 全局布局

- 画布：1980 x 1080，宽屏展示。
- 顶部栏：系统名、当前问答场景、历史会话、新建对话。
- 左侧栏：会话列表和搜索，不再承载业务菜单。
- 中间主区：标题、场景标签、消息流、底部输入框和快捷操作。
- 右侧栏：上下文面板，展示资料、数据、方法和结果状态。
- 生成方式：运行 `python3 scripts/generate_design_assets.py` 可同步生成 SVG 源稿和 PNG 预览图。

## 对话式交互结构

### 1. 问答式审计首页

用户进入系统后看到一个类似 GPT/DeepSeek 的对话工作台：

- 左侧显示历史会话，例如“电梯维护费超标审计”“政策法规抽取”“dataset01 接入”。
- 中间由智能体发起引导语，用户可以直接输入审计目标。
- 底部提供快捷按钮：上传资料、连接数据、生成 SQL、导出报告。
- 右侧展示当前任务、资料状态、数据状态、方法状态和快捷建议。

### 2. 智能识别问答

用户通过对话上传政策法规、历史经验或直接描述问题。智能体自动抽取审计关注点，并在消息流中展示抽取结果预览。

右侧上下文面板展示：

- 资料包：政策 / 经验 / 描述
- 抽取进度：已识别的关注点数量
- 历史匹配：可引用案例数量
- 用户确认后的写入位置：私有思路库

### 3. 数据接入问答

用户用自然语言要求连接数据库或上传文件，例如“连接 localhost:3306 的 dataset01，并预览部门预算相关表”。系统在对话中返回连接状态、表数量、数据量和字段映射建议。

右侧上下文面板展示：

- 连接状态
- 临时库名称
- 数据量与清洗状态
- 待确认字段映射

### 4. 方法执行问答

用户要求“基于某条规则生成 SQL 并运行当前审计库”。系统返回 SQL 片段、执行状态和命中结果，用户可继续追问解释原因、优化 SQL、导出 Excel 或打包报告。

右侧上下文面板展示：

- 执行状态和耗时
- 命中疑点数量
- 归档状态
- 可执行动作：导出 Excel、打包报告

## 文字溢出处理

| 场景 | 规则 |
| --- | --- |
| 会话标题 | 1 行省略，悬浮显示完整标题 |
| 消息气泡 | 主要内容按自然段换行，长结果进入卡片或详情抽屉 |
| 右侧状态卡 | 标题 1 行，描述 1 到 2 行，超出省略 |
| 输入框占位 | 控制在 1 行，说明放入快捷操作或提示卡 |
| SQL / 表字段 | 使用代码卡片承载，长行省略并支持展开 |
| 快捷按钮 | 使用短动词短语，例如“上传资料”“连接数据”“生成 SQL” |

## 视觉建议

- 主色：#2b7bd8，用于用户消息、主按钮、选中会话和当前场景标签。
- 背景：#f4f7fb，主容器：#ffffff，右侧面板：#f7fbff。
- 消息气泡：用户消息使用蓝色，智能体消息使用浅蓝灰卡片。
- 状态色：成功 #137a4c，警告 #c15b18。
- 圆角：主容器 30px，会话/消息/状态卡 18px 到 24px。
- 阴影：仅用于顶部栏和主工作台容器，保持大模型产品的轻量感。
