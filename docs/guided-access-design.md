# 审计智能体引导式访问设计稿

本方案将原先左侧菜单栏改为“顶部全局入口 + 页面内任务引导”的访问方式。用户不再从菜单树切换模块，而是从首页选择当前要完成的审计任务，并在每个任务内按照步骤条完成输入、预览、确认和产出。

## 设计目标

- 去掉左侧菜单栏，释放横向空间，降低菜单层级带来的跳转感。
- 将“智能识别、数据接入、审计方法执行”统一为任务卡片入口。
- 每个工作台保留一个主目标、一个步骤条、一个右侧状态/结果区。
- 文案较长时优先换行展示，关键标题限制为 2 行，列表和表格字段使用省略号并提供完整内容查看入口。
- 减少页面间跳转：用户在当前流程内完成选择、补全、预览、入库、执行和导出。

## 全局布局

- 画布：1980 x 1080，内容最大宽度 1820，居中展示。
- 顶栏：高度 80，承载系统名、当前流程标签、用户身份。
- 任务导航：不使用左侧菜单；首页用三张任务卡片承接原功能分组。
- 流程页面：顶部放面包屑、标题和步骤条，中部采用主操作区 + 右侧实时状态区的双栏布局。
- 底部操作条：仅放当前步骤相关按钮，例如“上一步”“保存并继续”“生成结果”。
- 生成方式：运行 `python3 scripts/generate_design_assets.py` 可同步生成 SVG 源稿和 PNG 预览图。

## 文字溢出处理

| 场景 | 规则 |
| --- | --- |
| 页面标题 | 最多 1 行，超出使用省略号，完整标题在详情区展示 |
| 卡片标题 | 最多 2 行，每行建议不超过 14 个中文字符 |
| 卡片说明 | 最多 2 行，超出省略；把补充说明放入 tooltip 或“查看详情” |
| 步骤名称 | 6 到 8 个字优先，超过 8 个字自动换成两行 |
| 列表项 | 主标题 1 行省略，副标题 1 行省略；鼠标悬浮显示完整值 |
| 表格字段 | 固定列宽，长文本省略；单元格支持展开查看 |
| 按钮文字 | 使用动词 + 对象，尽量控制在 8 个字内 |

## 交互流程

### 1. 总入口

用户进入系统后看到三个任务卡片：

- 智能识别：接收政策法规、历史经验、自然语言描述，生成审计思路。
- 数据接入：连接数据库或上传文件，形成临时库并确认入库。
- 方法执行：选择审计思路，生成 SQL，运行验证，导出归档。

首页同时展示“继续上次任务”和“最近产出”，减少用户回到菜单查找的成本。

### 2. 智能识别

步骤为：选择材料 -> 上传/描述 -> 抽取补齐 -> 确认生成。

右侧固定展示识别进度和结果预览；用户无需跳转到历史资料或思路库页面，也能看到补齐状态。

### 3. 数据接入

步骤为：选择接入方式 -> 配置/上传 -> 预览清洗 -> 设为审计库。

数据库连接和文件导入在同一页切换，统一进入临时库预览。字段映射问题在预览阶段集中修正。

### 4. 方法执行

步骤为：选择思路 -> 生成 SQL -> 执行验证 -> 导出归档。

左栏改为“当前任务内的思路列表”，不再作为全局菜单。中间显示规则和 SQL，右侧显示执行状态和命中结果。

## 视觉建议

- 主色：#2b7bd8，用于步骤进度、主按钮和选中态。
- 背景：#f3f7fb，卡片：#ffffff，边框：#d9e4f2。
- 状态色：成功 #16a36f，警告 #f59e0b，错误 #ef4444。
- 圆角：大卡片 14px，小控件 10px。
- 阴影：仅用于主卡片和右侧结果区，避免层级过多。
